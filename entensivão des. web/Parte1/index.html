Intensivão / Parte 1


Tipos primitivos:

let nome = "João"; // String
let idade = 25; // Number
let ativo = true; // Boolean
let indefinido; // Undefined
let vazio = null; // Null


Arrays/Listas:

let frutas = ["Maçã", "Banana", "Laranja"];
console.log(frutas[0]); // "Maçã"


Objetos:

let pessoa = {
nome: "Maria",
idade: 30,
cidade: "São Paulo"
};
console.log(pessoa.nome); // "Maria"


Declaração de Variáveis: var, let e const:

var: Escopo global ou de função. Pode ser redeclarada e tem comportamento de "hoisting" (é movida para o topo no início da execução).

let: Escopo de bloco. Não pode ser redeclarada no mesmo escopo.

const: Escopo de bloco. Não pode ser redeclarada nem ter seu valor reatribuído.


Operadores(Racionais e Lógicos)

===: Estritamente igual (valor e tipo)
!==: Estritamente diferente (valor e tipo)

console.log(10 == "10"); // true (só compara valor)
console.log(10 === "10"); // false (compara valor e tipo)


&&: E / (AND)
||: Ou / (OR)

let idade = 18;
console.log(idade >= 18 && idade < 30); // true
console.log(idade >= 17 || idade > 15); // false


Estruturas de Seleção(if, else if, else)

let temperatura = 30;

if (temperatura > 35) {
--console.log("Muito quente");
} else if (temperatura > 25) {
--console.log("Quente");
} else {
--console.log("Agradável");
}

Switch: Usado quando temos várias condições baseadas no valor de uma variável.

let diaSemana = 3;

switch (diaSemana) {
--case 1:
----console.log("Segunda-feira");
----break;
--case 2:
----console.log("Terça-feira");
----break;
--case 3:
----console.log("Quarta-feira");
----break;
--default:
----console.log("Dia inválido");
}

Operador Ternário

É uma forma compacta de escrever uma condição if-else.

let idade = 18;
let mensagem = (idade >= 18) ? "Maior de idade" : "Menor de idade";
console.log(mensagem); // "Maior de idade"
