Laços Definidos

1. for
O laço for é usado quando sabemos exatamente quantas vezes queremos repetir um bloco de código. Ele é composto por três partes: inicialização, condição e incremento.

for (inicialização; condição; incremento) {
// bloco de código a ser executado
}

exemplo:

for (let i = 0; i < 5; i++) {
--console.log(i); // Exibe 0, 1, 2, 3, 4
}


2. for in

O laço for in é utilizado para iterar sobre as chaves de um objeto ou os índices de um array.

for (variável in objeto) {
// bloco de código a ser executado
}

exemplo em objeto:

let pessoa = { nome: "João", idade: 25 };

for (let chave in pessoa) {
--console.log(chave, pessoa[chave]); // Exibe "nome João" e "idade 25"
}


exemplo em array:

let frutas = ["Maçã", "Banana", "Laranja"];

for (let i in frutas) {
--console.log(i, frutas[i]); // Exibe 0 "Maçã", 1 "Banana", 2 "Laranja"
}


3. for of

O laço for of é utilizado para iterar sobre os valores de um array ou de outros objetos iteráveis, como Strings, Sets e Mapas.

for (variável of iterável) {
// bloco de código a ser executado
}

let frutas = ["Maçã", "Banana", "Laranja"];

for (let fruta of frutas) {
--console.log(fruta); // Exibe "Maçã", "Banana", "Laranja"
}


4. forEach

O método forEach é uma função de array que executa uma função para cada elemento do array. Ele não retorna um novo array e não pode ser interrompido.

array.forEach(function(elemento, indice) {
// bloco de código a ser executado
});


exemplo array:

let frutas = ["Maçã", "Banana", "Laranja"];

frutas.forEach(function(fruta, indice) {
--console.log(indice, fruta); // Exibe 0 "Maçã", 1 "Banana", 2 "Laranja"
});


Exemplo com Arrow Function:

frutas.forEach((fruta, indice) => {
console.log(indice, fruta); // Exibe 0 "Maçã", 1 "Banana", 2 "Laranja"
});


Resumo

for: Para quando sabemos o número de iterações.
for in: Para iterar sobre chaves de objetos ou índices de arrays.
for of: Para iterar sobre valores de arrays ou objetos iteráveis.
forEach: Para aplicar uma função a cada elemento de um array.
