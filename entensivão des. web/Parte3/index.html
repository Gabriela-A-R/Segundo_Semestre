Promises:

Em JavaScript, uma Promise é um objeto que representa a eventual conclusão ou falha de uma operação assíncrona. Uma promise pode ter três estados:

Pendente (Pending): Quando a operação ainda não foi concluída.
Resolvida (Fulfilled): Quando a operação foi concluída com sucesso.
Rejeitada (Rejected): Quando ocorreu um erro ou a operação falhou.

Para criar uma promise, você usa o construtor Promise, que recebe uma função com dois parâmetros, resolve e reject, usados para definir o resultado da promise:

const minhaPromise = new Promise((resolve, reject) => {
--let sucesso = true;

--if (sucesso) {
----resolve("A operação foi bem-sucedida!");
--} else {
----reject("A operação falhou.");
--}
});

No exemplo acima, resolve é chamado se a operação for bem-sucedida, e reject é chamado se houver algum problema.


Encadeamento de Promises com .then(), .catch() e .finally()

.then(): É chamado quando a promise é resolvida. Pode retornar um valor para a próxima promise no encadeamento.
.catch(): É usado para capturar erros ou rejeições que ocorrem em qualquer etapa da promise.
.finally(): Executado sempre ao final, independente do sucesso ou falha.


Exemplo Completo: Simulando uma Operação Assíncrona com setTimeout

Vamos simular uma operação assíncrona, como uma requisição a uma API, usando setTimeout.

------resolve("Dados recebidos com sucesso!");
----} else {
------reject("Erro ao buscar os dados.");
----}
--}, 2000);
});

minhaPromise

----console.log(mensagemSucesso);
----return "Processando os dados..."; // Passa essa mensagem para o próximo .then()
--})
--.then((novaMensagem) => {
----console.log(novaMensagem);
----})
--.catch((mensagemErro) => {
----console.error(mensagemErro);
--})
--.finally(() => {
----console.log("Requisição finalizada!");
});

Vamos simular uma operação assíncrona, como uma requisição a uma API, usando setTimeout.

Esse exemplo simula uma operação de busca de dados que leva 2 segundos para ser concluída. Se for bem-sucedida, executa os .then(). Se falhar, executa o .catch().
